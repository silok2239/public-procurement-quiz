공공조달관리사 3,000문항 공부 앱

구성
- 1과목 1,000문항
- 2과목 1,000문항
- 3과목 1,000문항
- 총 3,000문항
- 랜덤/순차 학습
- 해설 및 초급 학습 포인트
- 틀린 문제 저장 및 재풀이
- 학습 통계
- 오프라인 캐시(Service Worker) 포함

휴대폰 설치
1. 이 폴더를 HTTPS 주소에서 서비스합니다.
2. Android Chrome에서 해당 주소를 엽니다.
3. Chrome 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
4. 생성된 아이콘으로 앱처럼 실행합니다.

주의: 이 파일 자체는 APK가 아니며, HTTPS 웹주소가 있어야 휴대폰에서 설치형 웹앱(PWA)으로 사용할 수 있습니다.
